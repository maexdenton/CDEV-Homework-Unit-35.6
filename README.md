# 🌐 AwesomeNetwork - Социальная сеть на ASP.NET Core

**AwesomeNetwork** - это веб-приложение социальной сети, разработанное на платформе **ASP.NET Core MVC** с использованием **Entity Framework Core**, **ASP.NET Core Identity** и **SignalR**.

Проект представляет собой глубоко переработанную и функционально дополненную версию исходного репозитория [SkillfactoryCoding/AwesomeNetwork](https://github.com/SkillfactoryCoding/AwesomeNetwork).

> [!NOTE]
> Итоговый проект по модулю 35.6 курса SkillFactory: Домашнее задание по C# - ASP.NET Core (PJ-03)
