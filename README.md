# 🌐 AwesomeNetwork - Социальная сеть на ASP.NET Core

**AwesomeNetwork** - это веб-приложение социальной сети, разработанное на платформе **ASP.NET Core MVC** с использованием **Entity Framework Core**, **ASP.NET Core Identity** и **SignalR**.

Проект представляет собой глубоко переработанную и функционально дополненную версию исходного репозитория [SkillfactoryCoding/AwesomeNetwork](https://github.com/SkillfactoryCoding/AwesomeNetwork).

> [!NOTE]
> Итоговый проект по модулю 35.6 курса SkillFactory: Домашнее задание по C# - ASP.NET Core (PJ-03)

---

## 🚀 Основные улучшения и новые функции

По сравнению с исходным репозиторием исправлены ошибки архитектуры и маршрутизации, упрощена структура проекта и добавлены основные функции социальной сети:

### 👤 Профиль

- Добавлена страница "Моя страница" с личными данными пользователя.
- Реализована загрузка аватара и автоматическая заглушка при его отсутствии.
- Добавлено редактирование профиля с проверкой данных.
- Настроен двусторонний маппинг `User` и `UserEditViewModel` через AutoMapper.

### 👥 Друзья и подписчики

- Разделены списки друзей и подписчиков.
- Добавлена возможность быстро принять подписчика в друзья.
- Реализован поиск пользователей по имени, фамилии и email.
- Поиск доступен из общей шапки сайта.
- Для каждого пользователя отображается актуальное действие: добавить или удалить из друзей.

### 💬 Сообщения и диалоги

- Реализованы личные чаты с любыми пользователями.
- В чатах отображаются сообщения, время отправки и автопрокрутка.
- Добавлен список диалогов с последними сообщениями и количеством непрочитанных.
- При открытии чата сообщения автоматически отмечаются как прочитанные.

### ⚡ Уведомления SignalR

- Подключен ASP.NET Core SignalR для обмена сообщениями в реальном времени.
- Добавлен точный поиск пользователей через `CustomUserIdProvider`.
- Новые сообщения отображаются во всплывающих Toast-уведомлениях с фото отправителя, текстом и ссылкой на чат.

### 🛠 Исправления и оптимизация

- База данных и необходимые таблицы создаются автоматически при запуске.
- Исправлены ошибки входа, выхода и перенаправления после авторизации.
- Удалены лишние проекты, оставлен один актуальный.
- Упрощена навигация и унифицирован дизайн шапки сайта.

## 🛠 Стек технологий

* **Язык программирования:** C# (.NET Core)
* **Фреймворк:** ASP.NET Core MVC
* **База данных и ORM:** Entity Framework Core (SQL Server / LocalDB)
* **Аутентификация и авторизация:** ASP.NET Core Identity (Cookie-based)
* **Real-time взаимодействие:** ASP.NET Core SignalR
* **Маппинг:** AutoMapper
* **Фронтенд:** Razor Views, HTML5, CSS3, JavaScript, Bootstrap, jQuery, Font Awesome

## 📂 Структура проекта

```text
AwesomeNetwork/
├── Controllers/                      # Контроллеры MVC
│   ├── AccountManagerController.cs   # Управление профилем, поиск, друзья
│   ├── HomeController.cs             # Стартовая страница, логин/регистрация
│   ├── MessageController.cs          # Личные сообщения и чаты
│   └── RegisterController.cs         # Обработка регистрации
├── Data/                             # Контекст базы данных EF Core
│   └── ApplicationDbContext.cs
├── Hubs/                             # SignalR хабы и провайдеры
│   ├── ChatHub.cs
│   └── CustomUserIdProvider.cs
├── Models/                           # Доменные сущности (User, Friend, Message)
├── ViewModels/                       # Модели представлений для форм и страниц
├── Views/                            # Razor-представления (UI)
└── wwwroot/                          # Статические файлы (CSS, JS, изображения)
```
